Aula 3 · 18 min

Extração pela assinatura e a trava que descarta

Ficha de catálogo, corpo de notícia, resumo de página: o agente escreve a partir de uma fonte, em lote. O risco é ele enfeitar e inventar. Aqui você chama o modelo pela assinatura, em modo só de leitura, lê o primeiro JSON da resposta e passa tudo por uma trava que descarta o item inventado.

Começar a aula

Nesta aula você vai

  1. 1A chamada do Codex em modo só de leitura, sem API
  2. 2Por que ler só o primeiro JSON da resposta
  3. 3A trava: título, palavras e números na fonte
  4. 4Descartar não é perder: é o que mantém o lote limpo

Objetivo: chamar o Codex ou o Claude pela assinatura para extrair de uma fonte e descartar, sem consertar, o item que falha na trava.

02 · Como o INEMA faz em lote

Clique em cada passo.

1. A chamada

O gerador de textos de notícias do INEMA chama o Codex com o pedido pela entrada padrão, sandbox só de leitura, sessão efêmera e saída num arquivo. Feche a entrada depois de mandar o pedido: sem isso o processo fica esperando.

No Claude Code, o mesmo pedido roda na pasta do projeto, com o AGENTS.md proibindo escrita fora da pasta de saída.

2. O primeiro JSON

Em 02/10/2026, respostas do Codex com o JSON duplicado quebraram a leitura do lote. A menor correção foi ler só o primeiro objeto completo (a função primeiroJson).

Não foi trocar de modelo nem reescrever o gerador: uma proteção de dez linhas.

3. Descartar

Das 159 notícias, 113 ganharam corpo de texto. As 46 sem texto ficaram assim porque a fonte exige login (25), tem pouco texto (18) ou deu 404 (1), e ficam com noindex, fora do sitemap.

Ninguém escreveu o que faltava à mão: melhor uma página a menos do que uma página com fato inventado.

4. Da API à assinatura

A primeira rodada de fichas usou API autorizada: 40 fichas extraídas e validadas por US$ 0,031. Os lotes seguintes passaram para o Codex pela assinatura.

A trava é a mesma nos dois caminhos; o que muda é quem paga a chamada.

import fs from 'node:fs'
import { apoiada, numerosNaFonte, tituloNaFonte } from './validar_extracao.mjs'
const [fonteArq, fichaArq] = process.argv.slice(2)
const fonte = fs.readFileSync(fonteArq, 'utf8')
const ficha = JSON.parse(fs.readFileSync(fichaArq, 'utf8'))
let validos = 0
for (const m of ficha.estrutura || []) {
  const ok = tituloNaFonte(m.titulo, fonte) && numerosNaFonte(m.detalhe || '', fonte)
  console.log(`${ok ? '✓' : '✗ descarta'}  módulo: ${m.titulo}`)
  if (ok) validos++
}
for (const campo of ['aprende', 'publico', 'constroi']) {
  for (const f of ficha[campo] || []) {
    const ok = apoiada(f, fonte) && numerosNaFonte(f, fonte)
    console.log(`${ok ? '✓' : '✗ descarta'}  ${campo}: ${f}`)
  }
}
console.log(validos >= 3 ? `ficha enriquecida (${validos} módulos válidos)` : `não publica como enriquecida (${validos} módulos válidos)`)
primeiroJson (do gerador de textos do INEMA)
function primeiroJson(txt) {
  const ini = txt.indexOf('{')
  let prof = 0, str = false, esc = false
  for (let i = ini; i < txt.length; i++) {
    const c = txt[i]
    if (str) { if (esc) esc = false; else if (c === '\\') esc = true; else if (c === '"') str = false; continue }
    if (c === '"') str = true
    else if (c === '{') prof++
    else if (c === '}' && --prof === 0) return JSON.parse(txt.slice(ini, i + 1))
  }
  throw new Error('JSON incompleto')
}

04 · Prática: uma extração com trava

Escolha um item do seu site que tem página própria com texto.

E1 · Extrair pela assinatura

30 min

Salve o texto da página em fonte.txt, monte o pedido.txt com o prompt extrativo e rode a chamada do Codex (ou o mesmo pedido no Claude Code). Repita com um pedido livre, "de forma atraente", para comparar.

Pronto quando: você tem saida.txt e saida-livre.txt, as duas em JSON, e nenhuma chave de API foi usada.

E2 · Rodar a trava

20 min

Copie o validar_extracao.mjs e o valida-ficha.mjs para a pasta e rode nas duas saídas. Anote o que foi descartado e por quê.

Pronto quando: uma anotação lista cada item descartado com o motivo (título, palavras ou número fora da fonte), e só a ficha com 3 ou mais módulos válidos está marcada para publicar.
