Lesson 6 · 16 min

Automatic weekly report and the agent that reads it and proposes

The observer closes the machine: every week, a script gathers non-branded Search Console data, the indexing of the key pages, and the position of the target queries into one report. An agent reads it and proposes three actions, each with the line that justifies it. You approve what becomes a task.

02 · How INEMA runs the observer

Tap each step.

1. The script

In INEMA's SEO project, a script runs the non-branded export, inspects the key URLs, reads the positions of the target queries, and writes the report compared with the previous week. With the no-API option, it only rebuilds the report from what is already saved.

The public version of the export is the method's gsc_semanal.py; the report around it fits in a short script that the agent can build for you.

2. The schedule

Cron runs every Tuesday at 9 a.m. and only generates the files. The commit stays manual: you look before you save.

Using the Search Console API for this measurement was authorized on 10/05/2026. It's your own data, but the authorization applies to that purpose.

3. What the agent looks for

A non-branded query that grew; a page with impressions and no clicks (rewrite the title and description); a query with impressions and no dedicated page (a content plan validated for free).

If nothing changed for weeks, the method's Plan B tells you what to look at: crawling, demand, title, or authority.

4. A real week

inema.club: 157 non-branded impressions across 51 queries, still with 0 non-branded clicks. inema.pro: the first 2 non-branded clicks, driven by "curso jev". Indexed: 13 of 14 key URLs; /eventos/ is missing.

The Spanish page, indexed on Oct 3, was already showing up for queries like "aprender ia" and "cómo aprender ia", at positions 29 to 61.

03 · The export, the schedule, and the request to the agent

gsc_semanal.py needs your Search Console credential (free, see the script header).

Weekly non-branded export (public, inemaSEO method)
export GSC_SITES="sc-domain:seusite.com"
export GSC_MARCA="seusite|seu nome|erro comum de digitação"
export GSC_QUOTA_PROJ="<seu projeto no Google Cloud>"
python3 tools/gsc_semanal.py --dias 7 --saida dados/gsc
Schedule (crontab template: Tuesday at 9 a.m.)
0 9 * * 2 cd ~/projetos/seo-seusite && python3 tools/gsc_semanal.py --dias 7 --saida dados/gsc >> dados/gsc/cron.log 2>&1
Request to the observer agent
Read this week's report (the most recent reports/semana-*.md) and the one from the previous week.
Propose at most 3 actions for this week. For each one:
- the report line that justifies it (copied);
- the type: title/description, new page for a query, indexing, internal link;
- what changes and where;
- how we will know next week whether it worked.
Do not change anything, do not call any API. If the week shows nothing new, say so instead of inventing an action.

04 · Practice: one week of your site

If you don't have the API credential yet, export the week's queries from the Search Console panel (Performance → Export) and use the CSV.

E1 · The week's report

40 min

Run the non-branded export for the last week (or export from the panel) and ask the agent for a Markdown report with totals, branded, non-branded, and the 15 non-branded queries with the most impressions.

Done when: a file reports/semana-[date].md exists with totals split into branded and non-branded, and the numbers match the Search Console panel.

E2 · Three proposals and your decision

20 min

Give the observer request to the agent. Check each line cited in the report and decide.

Done when: you have up to 3 proposals, each with the line copied from the report and your decision (approved, with the task created, or rejected, with the reason).
